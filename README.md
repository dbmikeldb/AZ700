## AZ700 Study Repo
This repo contains all the technology I deployed while studying for my AZ700 exam in the order I studied them, following Microsoft's official self-paced study guide here:
https://learn.microsoft.com/en-us/training/paths/design-implement-microsoft-azure-networking-solutions-az-700/


I deployed each resource via the Azure portal a few times before moving to use the Powershell scripts.

The code here and the infrastructure it deploys are not intended to provide a complete study experience but rather partially automate the provisioning of resources to study with.

Microsoft's documentation should be referenced to understand the technology.
